## Правила, которые действуют на всех этапах
- **Каждая функция — отдельный модуль** в своей ветке Git. Ошибка внутри модуля не роняет остальное приложение. Как устроено: [[architecture]].
- **Ветки Git:** каждая функция в ветке `feature/<название>`, в основную — после проверки.
- **Быстродействие**: вкладка рисуется только при первом открытии; длинные списки — через `FlatList`. Сначала замер, потом оптимизация.
- **Итог для телефона — APK**, который работает без компьютера: `pnpm android:release`.

## Этап 2. «Здоровье» v1 — замеры
- 🔄 Модуль `packages/health`, таблица замеров в SQLite (вес, обхваты). Ветка `feature/health-measurements`, проверено в браузере; ждёт проверки на телефоне.
- 🔄 Вкладка «Здоровье»: сводка по зонам с изменением, экран ввода, график и список замеров по каждой зоне, удаление замера. Там же.

## Техдолг
- ⬜ Переход на Expo SDK 58, после него удалить `patches/expo-sqlite@57.0.1.patch`.
- ⬜ Лишние разрешения в APK: `SYSTEM_ALERT_WINDOW` и `READ/WRITE_EXTERNAL_STORAGE` пришли из шаблона Expo (отчёт слияния манифеста), в коде приложения не используются. Убрать через `android.blockedPermissions` в `app.json` (`@expo/config-plugins` 57.0.7 ставит им `tools:node="remove"`).
