# Заметки проекта «Хата» (бывший Ecosystem)

Эта папка — память проекта. Её можно открыть в Obsidian как хранилище (Open folder as vault).
Claude читает эти заметки в начале сессии и дописывает решения.

- [[roadmap]] — план разработки по этапам
- [[architecture]] — как устроено приложение: нативная сборка, APK, модули
- [[decisions]] — журнал решений
- [[qa]] — полная проверка функций: что проверено, найденные ошибки
- [[health-module]] — модуль «Здоровье»: тренировки по образцу FitAI, вес, подсказки
- [[food]] — модуль «Еда»: дневник, калории и БЖУ, сканер штрих-кода, норма калорий
- [[wearables-api]] — кольца и браслеты с API, данные об окружающей среде
- [[signing-key]] — свой ключ подписи и переход на `by.hata.app` с переносом данных (пошагово)
- [[guide]] — как устроен проект: где что лежит, как читать код (для начинающих)
- [[proposals]] — предложения команды агентов (2026-10-19): дизайн, функции, безопасность, вопросы к пользователю
- `research/` — полные отчёты команды с источниками и проверкой фактов, ревью кода. Команда 2026-10-22: [[research/superapp-architecture]] (супер-приложение и «Мова»), [[research/design-hata]] (цвета и тёмная тема, макеты — `research/design-hata-mockups.html`), [[research/security-legal]] (безопасность и право), [[research/code-review-2]] (ревью), [[research/pricing]] (цена)
