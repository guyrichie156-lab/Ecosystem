# APK для установки на телефон

Здесь только готовые файлы приложения, без кода. Код — в остальных ветках.
Все APK подписаны одним и тем же отладочным ключом шаблона Expo, поэтому новый ставится поверх старого с сохранением данных.

Установить с компьютера (телефон подключён кабелем): `adb install -r <файл>.apk`.

## ecosystem-2026-10-20.apk — новый
Скачать: https://github.com/guyrichie156-lab/Ecosystem/raw/apk/ecosystem-2026-10-20.apk

- Собран 2026-10-20 из ветки `feature/food` (e33aec4). В ней лежат `feature/health-fitness` и `feature/finance-ux`, а под ними — всё из третьей сборки и чистка кода `feature/code-cleanup`.
- Что нового:
  - три вкладки: «Финансы», «Здоровье», «Еда»;
  - «Здоровье» устроено как FitAI: «Тренировка / Упражнения / Отдых мышц», профиль 👤;
  - «Еда»: калории и БЖУ, норма по формуле, базовые продукты, сканер штрих-кода;
  - в «Финансах» нажимаются итоги месяца, а у «Бюджетов» появилось объяснение.
- Новое разрешение — камера, для сканера. Разрешение на процент жира из Health Connect убрано.
- Android 8.0 и новее, процессоры ARM (`arm64-v8a`, `armeabi-v7a`).
- 77 529 334 байт, SHA-256 `aa26a53a18fa494e4b7520307185b2769f04acbdcf76832452b124e32e37488e`.
