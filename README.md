# APK для установки на телефон

Здесь только готовые файлы приложения, без кода. Код — в остальных ветках.
Все APK подписаны одним и тем же отладочным ключом шаблона Expo, поэтому новый ставится поверх старого с сохранением данных.

Установить с компьютера (телефон подключён кабелем): `adb install -r <файл>.apk`.

## hata-1.1.0-sign-first.apk — новая «Хата» (`by.hata.app`), сначала подписать своим ключом
Скачать: https://github.com/guyrichie156-lab/Ecosystem/raw/apk/hata-1.1.0-sign-first.apk

- **Не ставить на телефон как есть.** Сначала подписать своим ключом — пошагово в `notes/signing-key.md` (ветка `max/jolly-feynman-ykq4yw`). Иначе потом подписанная версия поверх не встанет.
- Собран 2026-10-24 из ветки `feature/hata-package` (586512a): имя пакета `by.hata.app`, версия 1.1.0. Остальное — как в `ecosystem-2026-10-24.apk`.
- Для телефона это новое приложение: данные переносятся через «⚙ → Резервная копия».
- 77 412 566 байт, SHA-256 `11fd79b22a688c4e788278f8d1e855c15734335f4b8f5ea8b9f0072b213d194c` — сверить командой `Get-FileHash` перед подписью.
