# APK для установки на телефон

Здесь только готовые файлы приложения, без кода. Код — в остальных ветках.

## ecosystem-2026-10-17.apk
- Собран 2026-10-17 в облаке из ветки `feature/health-connect` (коммит 4de23dc).
- «Финансы» (без истории транзакций) и «Здоровье» с Health Connect.
- Android 8.0 и новее, процессоры ARM (`arm64-v8a`, `armeabi-v7a`).
- Подписан отладочным ключом шаблона Expo.
- 65 746 830 байт, SHA-256 `fcee0bd1c96fec4dfe5781d8465866739f50a15de2c0c980909c77dad713bc98`.

Скачать: https://github.com/guyrichie156-lab/Ecosystem/raw/apk/ecosystem-2026-10-17.apk

Установить с компьютера (телефон подключён кабелем): `adb install -r ecosystem-2026-10-17.apk`.
